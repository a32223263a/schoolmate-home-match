# 자취메이트 MVP 구현 계획

## 범위
모바일 중심 웹앱. 서버 없이 브라우저 내 상태(새로고침 시에도 유지되도록 기기 저장)로 전체 흐름을 시뮬레이션합니다. 실제 결제·GPS·이메일 발송은 포함하지 않습니다.

## 화면
1. **로그인 / 학교 인증** (`/login`) — 단국대 이메일(@dankook.ac.kr) 입력 → 인증코드(시뮬레이션, 화면에 표시) 입력 → "위치 인증" 버튼으로 500m 인증 배지 부여 → 홈 이동. 미인증 시 다른 화면 접근 시 로그인으로 이동.
2. **홈 피드** (`/`) — 쉐어 카드(품목명, 남은 수량, 1인 가격, 거리, 주최자 매너온도), 카테고리 필터(전체/식재료/생필품/배달비), 우하단 '쉐어 등록' 버튼.
3. **쉐어 등록** (`/create`) — 품목명, 카테고리, 총 수량/소분 수량, 가격, 픽업존 선택(정문 GS편의점 택배함, 기숙사 무인 보관함 등), 마감 시간. 등록 후 상세로 이동.
4. **쉐어 상세** (`/share/$id`) — 상세 정보, 주최자 신뢰도, 보증금 안내, '참여하기' → 보증금 예치 확인 시트 → 예치 완료 후 픽업 화면 이동.
5. **알림** (`/notifications`) — 참여·예치·수령 등 상태 변화 알림 목록.
6. **마이페이지** (`/my`) — 프로필(매너온도, 인증 배지), 참여 중/등록한 쉐어와 상태(예치 완료 → 픽업 대기 → 거래 완료).
7. **픽업 / QR** (`/pickup/$id`) — 픽업존 위치 안내, QR 수령증, '수령 완료' 버튼 → 자동 정산 완료 → 매너 평가(별점 + 태그) 입력 → 주최자 매너온도 갱신.

## 공통 레이아웃
- 하단 네비게이션(홈, 쉐어 등록, 알림, 마이페이지).
- 데스크톱에서는 가운데 정렬된 모바일 폭(최대 약 480px) 카드 레이아웃으로 표시.

## 디자인
- 메인 민트 #10B981, 서브 그레이 #F3F4F6, 포인트 다크 #111827 (디자인 토큰으로 등록).
- 클린 미니멀, 둥근 카드, 한글 가독성 좋은 Pretendard 폰트.

## 샘플 데이터
우유 1L 반반 쉐어(도보 3분, 1,800원), 계란 10구 소분(정문 GS앞, 2,500원), 휴지 30롤 소분, 치킨 배달비 쉐어, 양파 1망 등 6~8개 + 주최자 프로필.

## 테스트
- 정산 상태 전이, 보증금·1인 가격 계산, 매너온도 갱신 규칙 단위 테스트.
- 브라우저로 로그인 → 등록 → 참여 → QR 수령 → 평가 전체 흐름을 모바일/데스크톱 크기에서 확인.

## 기술 메모
- TanStack 라우트 파일별 페이지 + 각 페이지 head 메타데이터.
- 상태는 React Context + localStorage(하이드레이션 후 로드), QR은 `qrcode.react`.
